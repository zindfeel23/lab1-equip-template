# Ответы на вопросы

## 2. Дюп Валеры

Минимальный пример в 3 строки:

```python
sword = valera_equip.Item("меч", "right_hand")
player.inventory.append(sword)
valera_equip.equip(player, sword)
```

После этого меч и в инвентаре (sword in player.inventory), и в слоте
(player.slots["right_hand"] is sword). Одна вещь в двух местах.

Почему так. В equip Валеры написано:

```python
inventory = _drop(player.inventory, item)
```

_drop не меняет список, а возвращает новый список без item. Результат
кладется в локальную переменную inventory, а не в player.inventory. Поэтому
player.inventory не изменился, и меч в нем остался. Дальше
player.slots[item.slot] = item кладет тот же меч в слот. Получается один
объект и две ссылки на него. Когда потом делаешь unequip, меч еще раз
добавляется в инвентарь, и там их становится два.

У меня по-другому: я удаляю вещь из player.inventory через remove, поэтому
после equip меч лежит только в слоте. Это проверяет тест test_my_equip_no_dup.

## 3. Сломанная вещь

У Item есть __bool__, который возвращает durability > 0. У сломанной вещи
durability = 0, значит bool(вещь) = False. Поэтому if player.slots[slot]:
путает сломанную вещь с пустым слотом.

Пример, где это видно:

```python
broken = equipment.Item("сломанный", "right_hand", power=10, durability=0)
player.slots["right_hand"] = broken
if player.slots["right_hand"]:
    # сюда не зайдет, хотя слот занят
```

В старом equip это ломало сохранение: сломанная вещь в слоте не
возвращалась в инвентарь (проверка if old: не срабатывала) и просто
затиралась новой. Вещь пропадала.

Починил тем, что проверяю пустоту через is None, а не через bool:

```python
if player.slots[slot] is not None:
```

Силу считаю через item.durability > 0, чтобы сломанная давала 0.

## 4. Некуда вернуть

Выбрал вариант "отказать". Если при надевании двуручного вещи из рук не
влезают обратно в инвентарь, equip возвращает False и ничего не меняет.

Почему так. Операция либо полностью прошла, либо ничего не изменилось. Нет
промежуточных состояний. Вещи не создаются и не теряются, инвариант работает
сам собой. Игроку понятно: освободи место и надень.

Кто может злоупотребить. У этого варианта почти нет способа получить выгоду:
нельзя задюпить вещь или выкинуть нужную. Единственное, что можно сделать,
это самому забить инвентарь и руки и не смочь надеть двуручное. Но это вредит
только самому игроку, выгоды нет.

Для сравнения: если выбрасывать вещи на землю, то equip можно было бы
использовать как бесплатное выбрасывание в обход вместимости. А если надевать
частично, получались бы кривые состояния, на которых можно строить новые дюпы.
